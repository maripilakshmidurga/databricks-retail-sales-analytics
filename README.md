# Databricks Retail Sales Analytics

## Project Overview
This project analyzes retail sales data using Databricks to understand sales performance across products, regions, months, and product categories.

The project was completed as part of the Data Engineering Foundations & Databricks hands-on assignment at Innomatics Research Labs.

## Tools and Technologies
- Databricks
- Unity Catalog
- Databricks SQL
- Databricks Genie
- Databricks AI/BI Dashboards

## Dataset
**Table:** `innomatics.default.sales_data`

The dataset contains 1,000 records and 13 columns, including product details, sales amount, quantity sold, region, sales date, customer type, payment method, and sales channel.

## Business Questions
1. What is the overall sales performance?
2. Which five products generated the highest sales revenue?
3. Which regions performed best?
4. How did sales revenue change month by month?
5. Which product categories contributed the most to total sales?

## Implementation
- Organized the sales table using Unity Catalog.
- Explored the dataset and its columns.
- Wrote and executed five SQL queries.
- Used Databricks Genie to explore business questions in natural language.
- Created and published an interactive AI/BI dashboard.

## Dashboard Features

### KPI Cards

### Visualizations
